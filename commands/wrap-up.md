Run a full session wrap-up.

## Workflow

### 1. Review What Was Done

Scan the conversation for:
- Files created or modified (list with paths)
- Memory files updated (STATUS.md, goals.md)
- Knowledge files updated (knowledge/ subdirectories)
- Decisions made that haven't been written down yet

### 2. Check Memory Consistency

- Does STATUS.md reflect active decisions from this session?
- Does goals.md Active Decisions Log match STATUS.md deadlines?
- Any confirmed facts that should be in memory but aren't?

### 3. Find Uncaptured Items

Check if this session produced:
- A decision worth logging in STATUS.md or goals.md
- A pattern or finding worth adding to knowledge/
- Any confirmed external resource IDs (URLs, sheet IDs, etc.)

### 4. Check CLAUDE.md Staleness

- Any new command pattern needed?
- Any routing rule that's now wrong?
- Any content that's become factually stale?

### 5. Present Report

- **Captured**: what was written down this session
- **Flagged**: things needing user input before writing
- **Suggested**: improvements for next session

Keep it concise. Verify, don't re-create.
